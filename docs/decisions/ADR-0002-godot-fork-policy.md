# ADR-0002: наш код живёт снаружи дерева Godot

- **Дата:** 2026-09-12
- **Статус:** принято

## Контекст

Из ADR-0001 следует форк Godot. Слово «форк» обычно означает, что код проекта смешивается с кодом
движка. Для соло-разработчика с длинным горизонтом это означает регулярный разбор конфликтов при
каждом обновлении upstream — и постепенную потерю границы между «наше» и «чужое».

## Решение

1. `godot/` — **git submodule**, чистый upstream-checkout, пин **по тегу** (`4.7.2-stable`), не по ветке.
2. Наш код живёт в `modules/` и подключается снаружи: `scons custom_modules=../modules`.
3. Любая правка внутри `godot/` требует **отдельного ADR**, где записано: что именно патчится, почему
   это нельзя было сделать модулем, и как патч переносить при обновлении.

## Почему

- `git status` остаётся честным: он показывает только наши изменения.
- Обновление Godot — это смена тега submodule и пересборка, а не разбор конфликтов в своём же коде.
- Патчи внутрь движка перестают быть незаметными: каждый стоит ADR, и потому их будет ровно столько,
  сколько действительно необходимо.
- Пин по тегу, а не по ветке: иначе `git submodule update` однажды притащит чужую регрессию в
  середину отладки, и её будут искать в своём коде. Прецедент есть — регрессия OpenXR+Vulkan на
  Android в Godot (issue #115924), закрытая PR #116226.

## Отвергнутые альтернативы

**Копировать модули в `godot/modules/`** — стандартный путь из туториалов. Отвергнуто: смешивает наше
и чужое, ломает `git status` как инструмент, делает обновление движка дорогим.

**GDExtension вместо модулей.** Не отвергнуто окончательно, отложено. GDExtension даёт сборку без
пересборки движка, но не даёт доступа к внутренностям рендера — а он, судя по бюджетам Quest 3,
понадобится. Если окажется, что не понадобился, этот ADR пересматривается: GDExtension дешевле.

**Полный форк с собственной историей** (не submodule). Отвергнуто: при соло-ресурсе стоимость
поддержки расхождения превышает выгоду, пока реальных патчей в движок нет ни одного.

## Когда пересматривать

- Число патчей внутрь `godot/` перевалило за единицы — submodule перестаёт окупаться, нужен полный форк.
- Выяснилось, что доступ к внутренностям рендера не нужен — вернуться к GDExtension.
- Upstream Godot сменил систему сборки и `custom_modules` перестал работать.
