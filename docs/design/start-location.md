# Стартовая локация

Проектный документ этапа Ф3. Что лежит в стартовой локации и зачем именно это.

## 1. Зачем локация

До этапа Ф3 приложение запускалось в пустоте: не с чем было сверить масштаб, некуда идти, не на что
встать. Стартовая локация — **проект по умолчанию** (этап 3): её видит человек, у которого ещё нет
своих проектов.

## 2. Состав (`world/levels/start_location.json`, 20×20 м)

| Что | Зачем |
|---|---|
| ровный пол 20×20 | база; на нём сверяется сетка пола |
| пандус ~10° | плавный подъём: разные способы перемещения ведут себя на нём по-разному |
| лесенка, ступени 0.18 м | проверка шага вверх у тела игрока |
| платформы 0.4, 0.9, 1.6 м | цели телепорта и высота, с которой можно упасть |
| зацепы у платформы 1.6 м (метка `climb`) | лазанье |
| стол-верстак 0.74 м | рабочая высота; на нём лежат предметы |
| столбы 1 и 2 м с делениями | **метки масштаба**: сразу видно, верен ли рост и масштаб мира |
| кубы: закреплённые и в руку (`body: grab`) | взятие предметов, будущий редактор объектов |
| узкий уступ и отмеченные площадки | точность луча телепорта |
| помещение с проёмом + триггер | **адаптивная загрузка**: интерьер подгружается при входе и выгружается через 2 с после выхода |
| стена 3.4 м с 14 зацепами в два ряда | лазанье с перехватом рук; шаг по высоте 0.45 м |
| площадка над стеной + кромка `ledge` | **перевал через край**: зона захвата и точка приземления |
| восемь табличек `sign` | подсказки у площадок; разворачиваются лицом к человеку |
| точка старта | где человек оказывается при запуске |

Интерьер помещения — отдельный файл `start_interior.json`: столы, полки, ящики, лампа.

## 3. Данные, а не сцена

Уровень — JSON по схеме, которая станет `scenes/*.json` формата проекта (этап 3):
объекты с UUID, типом, положением, поворотом, размером, цветом, телом (`static | grab | none`) и
метками. Загрузчик — `world/level_loader.gd`.

**Материалы общие на цвет**, а не на объект: цена отрисовки измерена по вызовам (4.04 мкс на вызов,
паспорт), поэтому важно число материалов, а не кубов. Сейчас **66 узлов на 9 материалов** (проверено дымовым прогоном и на шлеме).

## Когда обновлять этот файл

- Изменился состав локации или её размер.
- Появился формат проекта — локация становится проектом по умолчанию.
- Измерена цена кадра в локации — сослаться на паспорт.
- Появились ассеты glTF вместо кубов.
