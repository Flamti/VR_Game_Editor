```
????  все xr_ext — OpenXR не запущен
```

**Чему этот прогон научил (перенесено в устройство прибора):**

- `VK_EXT_fragment_density_map` на десктопной NVIDIA отсутствует — и это ПРАВДА,
  а не сбой: фовеация там делается через `fragment_shading_rate`. FDM — путь
  тайловых GPU. Прибор изначально считал отсутствие FDM отказом; исправлено на
  проверку семейства целиком с указанием, какой механизм найден.
- Наличие `VK_KHR_dynamic_rendering_local_read` на NVIDIA **ничего не говорит**
  про Adreno 740: на десктопе Vulkan 1.4, где расширение вошло в core.

## Что НЕ проверено

**Всё, что касается целевого устройства.** Quest 3 при `adb devices` 2026-09-12
не был подключён. Главный вопрос проекта — есть ли
`VK_KHR_dynamic_rendering_local_read` на Adreno 740 при Vulkan 1.3 — открыт.

Стоимость draw call, кадровый бюджет и поведение при троттлинге не измерялись
нигде: эти проверки в приборе ещё не написаны.

**Найден более короткий путь к XR-половине паспорта:** на машине активен
OpenXR-рантайм WiVRn (`~/.config/openxr/1/active_runtime.json` → Monado/WiVRn).
WiVRn стримит на автономный шлем по Wi-Fi, то есть строки `xr_ext` можно снять
со шлема, не собирая APK и не устанавливая Android SDK. Не проверено.

## Когда обновлять этот файл

- Прибор отработал на устройстве — заменить «не снято» числами и указать дату и версию прибора.
- Обновилась Horizon OS или драйвер — **перемерить**, старое перенести в раздел истории.
- Прибор получил новую проверку — добавить строку сюда.
- Любое число отсюда было использовано в коде — убедиться, что оно всё ещё актуально.
